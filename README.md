# Smart Broadband Usage

<p align="center">
  <img src=".github/logo.png" alt="mono-gtk-smart logo" width="128" />
</p>

A Mono GTK# program that shows broadband usage for Smart Telecom customers in
Ireland.

## What it does

It logs in to the Smart Telecom support forum, reads the broadband usage page
for your account and shows a summary and details, along with the daily and
summary usage charts.

## Tech

- C# with Mono and GTK#

## Building

Open the `.sln` file in MonoDevelop, or build it with Mono and run the resulting
`.exe` with `mono`. Requires GTK# 2.
